Heart clone using MONAI

How it was built

  1. The study

    A gated 4D cardiac CT of a truncal valve case, from the Jolley Lab at CHOP. 21 phases, 0.6 mm voxels, 2.5 GB.

  2. Finding the heart

    TotalSegmentator v2 through MONAI Physio, contrast aware. 58 structures in 400 s on an RTX 4050, on the reference phase only.

  3. Measuring the motion

    Greedy diffeomorphic registration warps the other 20 phases onto phase 15. The deformation fields are measured tissue displacement. 19.8 min.

  4. Fitting a browser

    One surface decimated with vtkDecimatePro, so every phase keeps the same vertices. Shipped as glTF morph targets. 7.0 MB.

Sources
